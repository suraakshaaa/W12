Chart.js: switching views and clicking bars

Library: Chart.js 4.4.1. In my meteorite project it draws a bar chart of 30 NASA meteorites. Buttons switch what the chart shows (mass or year), and clicking a bar selects that rock.

What works

  • Drawing a bar chart from a list of records is quick.
  • A log scale makes both a 60,000 kg meteorite and a 100 g one visible on the same chart.
  • Colouring each bar by rock type, and highlighting the selected bar, works with a function in the dataset options.

What does not work

Problem 1: "Canvas is already in use." A Chart.js chart owns the canvas it is drawn on. When a toggle button runs new Chart(...) on the same canvas again, Chart.js throws an error and the chart does not change. The fix is to call chart.destroy() before building the new chart.

Problem 2: destroying the chart inside its own click handler. If a bar click calls destroy() inside the chart's onClick, Chart.js is still handling that click and then fails with "Cannot read properties of undefined (reading 'handleEvent')". The fix is to wait with setTimeout(..., 0) and rebuild after the click has finished.

The code

Broken:

// toggle button
new Chart(canvas, config);              // second call: "Canvas is already in use"

// bar click
onClick: (e, items) => {
  selected = rocks[items[0].index].id;
  chart.destroy();                      // destroys the chart while it is still handling this click
  chart = new Chart(canvas, config);
}

Fixed:

// toggle button
chart.destroy();
chart = new Chart(canvas, config);

// bar click
onClick: (e, items) => {
  const id = rocks[items[0].index].id;
  setTimeout(() => {                    // wait until Chart.js has finished with the click
    selected = id;
    chart.destroy();
    chart = new Chart(canvas, config);
  }, 0);
}

Data: NASA Meteorite Landings. 30 rocks, 6 from each of 5 categories.
